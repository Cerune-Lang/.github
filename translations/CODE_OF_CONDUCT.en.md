# Code of Conduct

[日本語](https://github.com/Cerune-Lang/.github/blob/main/CODE_OF_CONDUCT.md) | English

Cerune-Lang hosts experiments and development work on programming languages, compilers, developer tools, and programs that use them. Please treat others with respect, regardless of experience or background.

## Expected behavior

- Discuss technical disagreements using code, observed results, and evidence.
- Respond considerately to questions from newcomers and to corrections.
- Respect privacy; do not share personal information or material not approved for publication.

## Unacceptable behavior

Personal attacks, discriminatory remarks, harassment, threats, repeated provocation, spam, and deliberate disruption are not acceptable. Criticism of technology is distinct from hostility toward a person.

## Scope and moderation

This code applies to project-related interactions, including issues, pull requests, reviews, and discussions, in Cerune-Lang repositories without their own code of conduct. If a repository has its own code, refer to it instead.

Depending on the situation, maintainers may issue warnings, hide or remove comments, close threads, or restrict participation. As these are personal projects, continuous moderation and specific response times cannot be guaranteed.

You can also use GitHub's reporting features for inappropriate content. Do not repost personal information or private conversations in public issues when reporting concerns. For security issues, follow the affected repository's security policy or the [shared policy](https://github.com/Cerune-Lang/.github/blob/main/SECURITY.md) if it has none.
