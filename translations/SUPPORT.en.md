# Support

[日本語](https://github.com/Cerune-Lang/.github/blob/main/SUPPORT.md) | English

- Usage: check the affected repository's README and documentation. Cerune language documentation is also available on the [official website](https://cerune.hokutaka.dev/).
- Bugs and feature requests: use the affected repository's issues after checking existing reports.
- Questions: use the repository's Discussions if enabled, or its issues otherwise.
- Security: do not post details publicly; follow the repository's security policy or the [shared policy](https://github.com/Cerune-Lang/.github/blob/main/SECURITY.md).

If you are unsure which project is relevant, see the [project list](https://github.com/Cerune-Lang/.github/blob/main/docs/projects.en.md).

These are personal, experimental projects; continuous support and specific response times are not guaranteed. Follow repository-specific guidance where available.
