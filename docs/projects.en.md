# Cerune-Lang projects

[日本語](projects.ja.md) · [Back to the organization](https://github.com/Cerune-Lang)

Public repositories in the Cerune-Lang organization. Refer to each repository's README for current features and usage.

## Language and developer tools

| Repository | Description |
| --- | --- |
| [Cerune](https://github.com/Cerune-Lang/Cerune) | Statically typed language with IR/MIR/SSA, multiple code generators, and IR/VM execution |
| [Sashimi](https://github.com/Cerune-Lang/Sashimi) | x86-64 instructions, assembly, and ELF/COFF object generation |
| [Tint*](https://github.com/Cerune-Lang/Tint-St) | Visualize Cerune intermediate representations, generated code, and execution results |
| [Cerune-vscode](https://github.com/Cerune-Lang/Cerune-vscode) | Cerune syntax highlighting and snippets for VS Code |

## Testing

| Repository | Description |

| [Parallax](https://github.com/Cerune-Lang/Parallax) | Differential testing of IR, MIR, VM, and other execution paths |
